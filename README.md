## Skills evidenced by these projects

- **Cloud and systems:** Azure resource groups, virtual networks, network security groups, Ubuntu administration, SSH hardening, firewall configuration, log management, patching and backups.
- **Networking:** Cisco IOS, SSH, RADIUS authentication, OSPF authentication, ACLs, VLANs, IPsec VPN, NAT/PAT, WPA2/AES and network validation.
- **Security analysis:** Network-traffic feature exploration, data preparation, Random Forest classification and regression, confusion matrices and recognising class-imbalance problems.
- **Documentation and testing:** Explaining design decisions, recording limitations, collecting configuration evidence and testing intended **and blocked** traffic.
